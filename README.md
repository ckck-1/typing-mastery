# ⌨️ Typing Academy

A modern, web-based typing practice platform designed for **speed, accuracy, and structured learning**. Typing Academy combines real-time typing tests, guided teaching modes, and social competition to help users level up their typing skills in a focused, distraction-free environment.

---

## 🚀 Overview

Typing Academy is a full-stack PERN-based application that provides:

* Real-time typing performance tracking
* Structured typing lessons with visual keyboard guidance
* Social competition via leaderboards and friends system
* Admin analytics dashboard for system monitoring

The platform is built for **desktop users with physical keyboards** and prioritizes precision, performance, and clean UX.

---

## 🎯 Features

### ⌨️ Typing Test Engine

* Live WPM (Words Per Minute) calculation
* Accuracy tracking in real time
* Error detection and highlighting
* Multiple modes:

  * Time-based (15s, 30s, 60s, 120s)
  * Word-based (10, 25, 50, 100 words)
  * Quote mode
  * Custom text mode

---

### 📚 Teaching Mode

* Step-by-step structured lessons
* Visual keyboard with finger placement guide
* Progressive difficulty (home row → full keyboard mastery)
* Interactive practice drills
* Optional progress tracking for registered users

---

### 👤 Authentication & Profiles

* Email + password registration
* OTP email verification
* Password reset system
* Guest mode (limited access)
* User profiles with avatars (Cloudinary)

---

### 🏆 Social System

* Global leaderboard (weekly, monthly, all-time)
* Friends-only leaderboard
* Friend request system (two-way approval)
* Challenge links ("beat my score")

---

### 🔔 Notifications

* In-app notification center
* Friend request alerts
* Score beat notifications
* Optional email notifications

---

### 📊 Admin Dashboard

* Active user analytics
* Average WPM tracking
* API performance metrics
* Manage typing passages
* User feedback review system
